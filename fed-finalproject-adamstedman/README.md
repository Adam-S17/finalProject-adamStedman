# Backpackers Travel
A one stop shop website for backpackers containing live weather updates and recommendations 

## File Structure
```
backpackers-hub/
├─ index.html          # Landing Page
├─ destinations.html   # Destination Page
├─ tours.html          # Tours / Activities Page
├─ planner.html        # Planner / Bookmarks Page
├─ tips.html           # Travel Tips / User Ideas Page
├─ css/
│  └─ style.css        # Main stylesheet
├─ js/
│  └─ main.js          # JS for interactivity
```
